# Veriforge

**Where my work becomes proof.**

Veriforge is my living evidence system for the systems I build, the decisions I make, the failures I learn from, and the proof I collect.

It is not a normal portfolio. It is a proof engine that maps my claims to evidence through case files, decision logs, failure ledgers, tests, demos, architecture, and interview-ready evidence packs.

## Product direction

Veriforge is built around one rule:

> If I cannot prove it, I do not claim it.

The system organizes my work into:

- Mission Control
- My Narrative
- Proof Claims
- Case Files
- Proof Wall
- Failure Ledger
- Decision Ledger
- Build Log
- Before / After
- Operating Style
- Interview Mode
- Ask Veriforge
- Evidence Packs

## No-bullshit rule

If I cannot prove it, I do not claim it.
If it is only an idea, I label it as an idea.
If it is not tested, I do not call it production-ready.
If it failed, I document the failure and the fix.
If I used AI, I explain how I directed, reviewed, tested, or validated the work.
